## Projects

### [FitLife — Modern Gym & Fitness Center](https://github.com/lohith-hash/Fitlifefitness)

A responsive website for a gym and fitness centre: a nine-product gym-tool catalogue, a 21-product
nutrition store with goal filters, three membership tiers, and WhatsApp enquiry routing with
pre-filled messages on every item. Built as a component-based static site — 14 HTML components, a
numbered 22-file CSS cascade and vanilla JavaScript modules, with no framework or build step.

`HTML` `CSS` `JavaScript` &nbsp;·&nbsp; [Live site](https://fitlifefitness7.vercel.app)

### [Developer Portfolio](https://github.com/lohith-hash/portfolio)

An editorial single-page portfolio with three switchable themes, project case studies, an image
lightbox with keyboard navigation, a reading-progress bar, a live IST clock and direct contact
channels. One HTML document, zero dependencies.

`HTML` `CSS` `JavaScript` &nbsp;·&nbsp; [Live site](https://portfolio-lohith-1e2a.vercel.app)

no external libraries — my main exercise in object-oriented design and file handling.

`Java`
